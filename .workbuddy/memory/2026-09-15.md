  - 覆盖扩展名：`.cs/.xaml/.csproj/.props/.targets/.config/.html/.md/.lua/.py/.sh/.editorconfig/.gitignore/.txt/.ini/.cfg` 等。
  - 跳过：加密文件（`88 7d 1c` 头，AI 不可改）、二进制（dll/so/exe/png…）、`.json`（注释会破坏严格 JSON 解析）、`.sln`（MSBuild 拒绝 `#` 注释）、`bin/obj/.git/.workbuddy`。
  - 混淆方式：原串每个字符间插入随机小写字母（`温a启b志c：d1e8...`），注释里同时保留明文 `温启志：18719361399` 便于检索。
  - 注释样式按扩展名区分：`//`(cs) `--`(lua) `#`(py/sh/ini/txt/gitignore/editorconfig) `<!-- -->`(xml 类/md)。
  - **关键**：XML 类文件（xaml/csproj…）水印必须插在根元素**内部**（紧跟根开标签之后），绝不能插在文件末尾（根元素之后）或根元素之前——否则 XAML 报 `MC3000 markup at the root level is invalid (line 1, position 1)`。
- **双重 BOM 大坑（本项目高价值教训）**：Python `text.encode('utf-8-sig')` 本身会再写一次 BOM；若同时手动 `out = BOM + text.encode('utf-8-sig')` 会变**双重 BOM**，第二个 BOM 解码成文本里的 U+FEFF 字符，XAML 在 (1,1) 处遇非法字符直接 MC3000。修正：检测到原文件带 BOM 时，用 `'utf-8-sig'` 解码（剥离一个 BOM），再 `text.encode('utf-8')`（**不要** utf-8-sig）+ 手动 `BOM + out` 只加一次；并防御性 `text.replace('\ufeff','')` 清掉残留 U+FEFF。
- 结果：76 个文本源文件全部含署名水印（`UNSIGNED=0`），构建 -c Debug **0 错误 0 警告**。RoiCanvas.xaml 顶部原有预存注释 `<!-- 作者：温·启·志 编写 ▢ 联系 wx:187-1936-1399 -->`（含间隔点，不含连续"温启志"）保留未动，构建正常。
