## ncv_top_nav_colored_icons（emoji 灰色根因 + 矢量彩色图标）
- **用户反馈**：去掉彩色背景方块后导航图标仍是灰色。
- **根因**：WPF 的 TextBlock 在该环境把 Segoe UI Emoji 降级渲染为单色（灰色）字形，不显示彩色 emoji；单纯去掉背景无效。
- **方案**：放弃依赖 emoji 彩色渲染，改用 XAML 矢量彩色图标（DrawingImage），跨环境 100% 彩色、零依赖、随构建打包，彻底解决灰色。
- **新增** Themes/Icons.xaml：8 个 DrawingImage 资源（坐标 0-24）：
  - IcoProject 黄文件夹 / IcoCamera 深灰机身+蓝镜头 / IcoMotion 灰六角螺母
  - IcoComm 紫信号塔 / IcoVariable 绿计算器 / IcoFlow 橙分支箭头 / IcoEngineer 棕扳手 / IcoOperator 粉人像
- **App.xaml** MergedDictionaries 增加 Themes/Icons.xaml 合并。
- **MainWindow.xaml**：导航栏 8 个 AppleIconTile 替换为 Image Source={StaticResource IcoX} Width=24 Height=24。
- **验证**：dotnet build -c Debug 输出 obj17/bin17（csproj 临时加 obj\**;bin\**）→ 0 错误；已清理并还原 csproj。
- **旁注**：曾试 ImageGen 生成 PNG，但并行输出全归一目录且时间戳冲突覆盖，放弃；矢量方案更稳且零额度。
