- **App.xaml** MergedDictionaries 增加 Themes/Icons.xaml 合并。

  - 新增 `ScheduleDefectRefresh()`（仅当 SelectedTool==缺陷检测 && HasImage && _lastResults!=null 时 Stop+Start timer）与 `RedetectDefects()`（用当前参数对缓存结果仅重跑 DetectDefects，重绘绿/红叠加与列表，更新 DefectSummaryText）。

  - 缺陷参数卡内加「重置参数」按钮（绑定 ResetDefectCmd）；缺陷结果卡标题下加摘要 TextBlock（绑定 DefectSummaryText，红字）。

- **说明**：刷新只重跑 DetectDefects（不重匹配），更快；若需拖动后实时，可把 timer 改短。请 VS rebuild + F5，视觉工具页切到「缺陷检测」，加载图、框选模板、运行检测，再拖滑块即 1 秒后自动重检。

    - 尝试用 `_sharedImage` → `CurrentImagePath` → `tmplStep.ImageSource` 加载源图（`Cv2.ImRead(..., ImreadModes.Color)`）。

    - 最后设置 `DefectOptions` 并调用 `DetectDefects(_lastMatchResults)`；结果更新 `FlowDefectResults`/`DefectSummaryText`/`DefectOverlayImage`/`Status`。

- 构建: `dotnet build -c Debug` → **0 错误**。
- 验证建议: VS Rebuild + F5；跑「图像采集」→「模板匹配」→ 选中「缺陷检测」，调参数或点按钮后应能在图上看到红色缺陷叠加，底部列表显示缺陷。
