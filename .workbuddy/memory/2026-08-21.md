## ncv_hw 修复：点击脚本流程右侧不显示脚本编辑器

- **现象**：点「添加脚本流程」后，中间/右侧仍显示普通步骤视图，脚本编辑器（ScriptFlowView）不出现。
- **根因（WPF 依赖属性优先级）**：`Views/FlowView.xaml` 第 84 行 `ScriptFlowView` 同时写了本地属性 `Visibility="Collapsed"` 和 `<Style>` 里的 `DataTrigger`（FlowKind=="Script" → Visible）。WPF 中**元素本地属性值优先级高于 Style 触发器**，所以触发器永远被本地 `Collapsed` 压死，脚本视图恒隐藏。右侧 `ScrollViewer`(223) 和中间 `Grid`(98) 只靠 Style 触发器、无本地属性，写法正确不受影响。
- **修复**：删除第 84 行 `ScriptFlowView` 上的本地 `Visibility="Collapsed"` 属性（仅保留 `Grid.Column/ColumnSpan/Margin/DataContext`），让 `Style` 的默认 `Collapsed` setter + `Script` 触发 `Visible` 正常生效。
- **教训**：凡用 `DataTrigger` 控制 `Visibility` 显隐，**绝不能在元素上再写 `Visibility="..."` 本地属性**，否则触发器无效。需要默认隐藏时务必用 `Style.Trigger`/`Style.Setter` 而不是元素属性。
- **验证**：系统 .NET 10 SDK 后台 `dotnet build -c Debug` 通过，**0 错误 0 警告**。
