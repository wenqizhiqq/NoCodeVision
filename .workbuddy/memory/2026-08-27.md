## ncv_project_persist（项目真正落盘 bin/Projects）
- 需求：截图显示 `bin/Debug/net10.0-windows/Projects` 为空——原 `SaveCmd` 只改 Status、未真正写 `.ncv`，故文件夹为空。需保存时把 `ProjectItem` 真实序列化为 `.ncv` JSON 写入 bin/Projects，且启动/无项目时把示例工程落到磁盘。
- `ViewModels.cs`（`ProjectViewModel`，UTF-8-BOM+CRLF，用 Python 读写以防工具误判二进制）：
  - 新增 `private void SaveProject(ProjectItem item)`：`Directory.CreateDirectory(Path.GetDirectoryName(item.ProjectPath))` 后 `JsonSerializer.Serialize(item, WriteIndented)→File.WriteAllText(item.ProjectPath, json)`。
  - 新增 `private void SyncProjectsWithDisk()`：扫描 `AppPaths.ProjectsDirectory` 下 `*.ncv`；有文件则反序列化填回 `Projects`；无文件则把 `Projects` 中示例工程逐个 `SaveProject` 落盘。
  - 重写命令：`AddCmd`（新增→`Projects.Add`→`SelectedProject`→`try{SaveProject}`）、`DeleteCmd`（`Projects.Remove`+`File.Delete(ProjectPath)`+重选）、`OpenCmd`（`File.Exists` 时读 `.ncv` 反序列化替换 `Projects[idx]`）、`SaveCmd`（`SaveProject(_selectedProject)`+更新 Status/ModifyTime）。
  - 构造函数尾部：`SyncProjectsWithDisk(); if (Projects.Count>0) SelectedProject = Projects[0];`
- 修复脚本叠加导致的文件损坏：recover 脚本遗留一份 `SyncProjectsWithDisk` 孤儿块（引用 `Projects`/`SaveProject`）误置于 `OperatorViewModel` 内，引发 CS0103 ×4。已用 Python 删除该孤儿块（3072 行干净）；确认 `SaveProject`/`SyncProjectsWithDisk` 各仅 1 定义、`ProjectViewModel` 拥有正确实现。
