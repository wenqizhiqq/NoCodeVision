## ncv_operator_run_all_flows_loop（操作员运行按钮：全部流程循环运行）
- 需求：操作员「运行」按钮要循环运行全部流程，只有点「停止」才跳出循环。
- 约束：操作员页 DataContext 是加密子类 `OperatorRunViewModel`（`OperatorRunViewModel.cs`、`OperatorView.xaml.cs` 均以 `88 7d 1c` 开头，IDE 编译时解密，明文层不可编辑）；其 `RunCmd`/`StopCmd`/`PauseCmd`/`EmergencyStopCmd`/`ResetCmd` 在加密层，无法改。故循环逻辑改放可编辑的基类 `OperatorViewModel`(`ViewModels.cs`) 与 `FlowViewModel`(`ViewModels.cs`)，并用不冲突的新命令名避免被加密子类隐藏。
- `FlowViewModel`（`ViewModels.cs`，UTF-8-BOM+CRLF，Python 读写）：
  - 新增 `public static FlowViewModel? Instance { get; private set; }`，构造函数置 `Instance = this;`（无需改加密的 `FlowView.xaml.cs` 即可让操作员页取到流程引擎）。
  - 抽出 `private async Task RunSingleFlowStepsAsync(VisionFlow flow, CancellationToken ct)`（原 `RunAllAsync` 单流程步骤循环体，含暂停等待、UI 重绘延迟、NextStepIndex 推进）。
  - 新增 `public async Task RunAllFlowsLoopAsync(CancellationToken ct)`：`IsRunning=true` 后 `while(!ct.IsCancellationRequested){ foreach(flow in Flows) await RunSingleFlowStepsAsync(flow,ct); }`，即不停循环全部流程，直到取消（停止）才跳出；finally 复位 `IsRunning/IsPaused` 并置状态文案。
  - `RunAllAsync`（单选流程）改为调用 `RunSingleFlowStepsAsync(_selectedFlow,_cts.Token)`，行为不变。
- `OperatorViewModel`（`ViewModels.cs`）：
  - 新增 `private CancellationTokenSource? _runCts;` 与命令 `RunAllFlowsCmd`/`StopAllFlowsCmd`。
  - `RunAllFlowsCmd`：`_ = StartLoopAsync()`（guard `_isRunning`）；`StopAllFlowsCmd`：`StopLoop()`（取消 `_runCts`）。
  - `StartLoopAsync()`：建 cts→`IsRunning=true`→`await FlowViewModel.Instance.RunAllFlowsLoopAsync(token)`→finally 复位；区分 `OperationCanceledException`(正常停止) 与其他异常。`StopLoop()`：`_runCts?.Cancel()`。
- `Views/OperatorView.xaml`（明文）：运行按钮 `Command="{Binding RunCmd}"`→`RunAllFlowsCmd`，停止按钮 `Command="{Binding StopCmd}"`→`StopAllFlowsCmd`（改绑可编辑基类命令，避开加密子类原 `RunCmd/StopCmd`）。`RunButtonText` 仍随基类 `IsRunning` 切换「开始检测/停止检测」。
- 构建验证：`dotnet build -c Debug` **0 错误**（14 个既有可空警告）。
- 注意/风险：加密子类原 `RunCmd/StopCmd`（真实机台控制状态机）现已不再被运行/停止按钮绑定；若其原本还负责启动物理设备（如传送带/气缸），循环跑的是流程内的视觉步骤（相机采集+模板匹配+测量+输出），机台运动需另在「工程师」页或合并到 `StartLoopAsync` 驱动 `HardwareManager.Instance.Motion` 才启动。暂停按钮若映射到 `FlowViewModel.IsPaused` 则对循环同样生效。
