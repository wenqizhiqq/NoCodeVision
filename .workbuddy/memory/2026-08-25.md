- ncv_scriptflow_lua_editor_enhance（ScriptFlowView）：
  - Lua 语法高亮：`Views/ScriptFlowView.Partial.cs` 内 `ApplyLuaHighlighting()` 用内嵌 XSHD 字符串（`LuaXshd` 常量）经 `HighlightingLoader.Load` 加载，绑定到 `Editor.SyntaxHighlighting`。配色：变量(identifier)=青绿 #0F766E，逻辑关键字(if/then/for/function/local/...)=紫 #9333EA，字符串=绿 #16A34A，数字=橙 #C2410C，注释(--)=灰 #8E8E93。Light 主题可读。
  - 点击变量取名称+值：`Editor.TextArea.MouseUp` 与 `Caret.PositionChanged` 触发 `UpdateVariableAtCaret()`，取光标词，在 `FlowViewModel.Variables`（`NoCodeVision.Scripting.VarItem` 集合，运行/断点后填充）查找同名，写入 `SelectedVariable`；未找到则构造临时 `VarItem` 显示「未监视/未运行」。右侧「变量检查」面板绑定 `SelectedVariable` 即显示。
  - 左侧耗时显示：`ScriptFlowView.xaml` 编辑器标题条左侧加「⏱ 耗时 {ScriptElapsedText}」（ms/s 由 VM `ScriptElapsedText` 提供）。
  - 注意：`VarItem` 命名空间歧义——`NoCodeVision.Scripting.VarItem`(Lua运行时) 与 `NoCodeVision.ViewModels.VarItem`(变量页面) 同名，Partial.cs 需全名引用 Scripting 版。
  - 构建验证：`dotnet build -c Debug` 0 错误。
