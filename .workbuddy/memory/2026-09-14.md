### 事故与恢复（重要）
首轮 patch 脚本把 `ViewModels.cs` 写坏为 **0 字节**：原因是 `save()` 用 `open('w')` 先截断文件，而脚本里 emoji 用 `\uD83D\uDCF7` 这类**代理对转义**在 Python 里是非法 lone surrogate，`f.write` 抛 `UnicodeEncodeError`，但文件已被截断清空。
- 恢复：`git restore ViewModels/ViewModels.cs`（HEAD = c3b4e3f，含未截断版本），重新跑修正后的脚本（图标改用中文单字「采/匹/测/缺/发/出/流」替代 emoji，彻底规避 surrogate 问题）。
- 教训：① 写源码的脚本绝不用 emoji 代理对，用中文/ASCII；② `save()` 应改用 `open(path,'r')` 先读校验、用临时文件+改名，避免截断即损毁；③ 改动前先 `git` 有提交兜底，截断可秒级恢复。
