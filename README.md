# NoCodeVision无代码视觉软件总结
NoCodeVision是基于.NET 10与WPF框架自主研发的无代码机器视觉上位机软件，配套自研SIMD+FFT加速的NCC模板匹配内核，对标商用视觉平台，面向工业自动化检测、定位场景，实现无需编程即可完成视觉项目搭建、调试与量产运行，和同系列NoCodeMotion无代码运动控制软件形成视觉+运动完整配套解决方案。

软件采用模块化分页架构，顶部导航包含项目、相机、通讯、变量、流程、工程师、操作员七大功能分区，划分工程师调试权限与操作员生产权限，适配现场调试与产线量产两套使用场景。相机管理模块支持多相机接入，可配置全局快门/卷帘相机的曝光、增益、分辨率、像素格式，提供连续采集、软触发、硬触发三种采集模式，支持多视野相机分组管理，适配多工位视觉检测方案，界面集成实时图像预览，方便调试人员快速确认成像质量。

可视化流程编排是软件核心能力，支持创建多套独立流程方案（主流程、定位流程、检测流程），内置图像采集、模板匹配、几何测量、逻辑判断、结果输出等标准化视觉算子。工程师通过拖拽添加步骤、配置ROI区域、设置匹配阈值、超时重试参数搭建检测逻辑，支持条件分支流程控制，模板匹配功能可完成工件定位基准查找，输出分数用于合格判定，检测结果可对接PLC完成通讯交互。流程面板支持单步调试、完整运行，实时展示各步骤耗时，便于性能优化。

工程师管理页面负责整机系统运维，展示视觉引擎、相机、通讯等核心模块运行状态，提供开发、调试、生产三种运行模式切换，可自定义日志输出等级，完整记录模板匹配耗时、相机连接状态等调试信息，支持日志导出排查现场故障，软件内置商用授权机制，保障项目合规落地。

底层采用C# WPF搭建前端UI，自研C++视觉算法内核，使用SIMD与FFT加速优化NCC模板匹配，提升图像匹配运算速度，摆脱对OpenCV、Halcon等第三方商用视觉库依赖，可控性更强，方便二次定制。整套软件广泛适配零部件定位、尺寸测量、缺陷检测、产品分拣等工业场景，降低机器视觉项目开发门槛，设备工程师无需精通视觉算法编程，依靠可视化界面完成相机标定、模板训练、检测流程搭建、通讯对接，缩短项目交付周期，适配中小型自动化设备厂商轻量化视觉项目落地。

整体来看，NoCodeVision兼顾易用性、运行性能与可扩展性，无代码可视化编排降低视觉应用开发门槛，自研算法内核保障匹配效率，搭配权限管理、日志诊断功能，覆盖视觉项目从调试、试产到长期量产的全流程需求，和自研无代码运动控制系统组合，可打造一体化视觉引导运动控制自动化方案。
